正多边形逼近计算流程文字文档
一、流程概述
开始 → 输入 n → i = 6 → x = 1 → s = 6 * sqrt(3) / 4 → i ≤ n/2？ → 计算 h → 更新 s → 更新 x → i = 2 * i → i ≤ n/2？（循环） → 输出 n、x → 完成

二、详细步骤说明
开始（起止节点）：计算流程启动
输入 n（处理节点）：输入参数 n
i = 6（处理节点）：初始化边数 i 为 6
x = 1（处理节点）：初始化边长 x 为 1
s = 6 * sqrt(3) / 4（处理节点）：初始化面积 s 为 6 倍根号 3 除以 4，即正六边形面积
i ≤ n/2?（判断节点）：判断当前边数是否小于等于 n/2；若是，进入循环体继续迭代；若否，输出结果
h = sqrt(1 - (x/2)^2)（处理节点）：根据当前边长计算高 h
s = s + i * x * (1-h) / 2（处理节点）：根据新增三角形面积更新总面积 s
x = sqrt((x/2)^2 + (1-h)^2)（处理节点）：根据几何关系更新边长 x
i = 2 * i（处理节点）：将边数翻倍
输出 n、x（处理节点）：输出计算结果 n 与 x
完成（起止节点）：流程结束

三、流程说明
本流程为带循环迭代的数值逼近计算流程。从正六边形出发，通过不断将边数翻倍并更新边长与面积，逐步逼近目标图形；循环条件为 i ≤ n/2，满足条件时继续迭代，不满足时输出最终的 n 与 x 值。
