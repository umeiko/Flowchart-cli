利润与亏损计算流程文字文档
一、流程概述
开始 → 读取收入（Read Income） → 读取成本（Read Cost） → 收入是否大于等于成本？ → [计算利润 / 计算亏损] → 输出结果 → 结束

二、详细步骤说明
开始（起止节点）：利润与亏损计算流程启动
Read Income / 读取收入（处理节点）：输入或读取收入金额
Read Cost / 读取成本（处理节点）：输入或读取成本金额
Income >= Cost? / 收入是否大于等于成本？（判断节点）：判断收入与成本的大小关系
Calculate Profit as Income - Cost / 计算利润 = 收入 - 成本（处理节点）：当收入大于等于成本时，按公式计算利润
Print Profit / 输出利润（处理节点）：显示或打印利润结果
Calculate Loss as Cost - Income / 计算亏损 = 成本 - 收入（处理节点）：当收入小于成本时，按公式计算亏损
Print Loss / 输出亏损（处理节点）：显示或打印亏损结果
结束（起止节点）：计算流程结束

三、流程说明
本流程为带分支判断的顺序流程。流程先依次读取收入和成本，然后通过“收入是否大于等于成本”进行二分支判断：满足条件则走“计算利润→输出利润”分支，否则走“计算亏损→输出亏损”分支，两个分支最终都到达结束节点。整体结构清晰，属于典型的条件分支型流程。
