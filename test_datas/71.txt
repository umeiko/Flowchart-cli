流程图符号示例文字文档
一、流程概述
开始/结束 → 判断 → 处理 / 数据输入 / 预定义子程序 → 文档A/文档B/多文档 / 手工输入/可选处理/延迟 → 回到开始/结束

二、详细步骤说明
start/terminator / 开始/结束（起止节点）：流程的起点和终点，通常用椭圆表示。
decision / 判断（判断节点）：菱形判断节点，根据条件分支出不同路径。
process / 处理（处理节点）：矩形处理节点，表示一般处理操作。
data (input) / 数据输入（处理节点）：平行四边形数据节点，表示数据输入。
predefined process/subroutine / 预定义子程序（处理节点）：双竖线矩形，表示调用预定义过程或子程序。
document A / 文档A（处理节点）：波形底矩形，表示生成或处理文档A。
document B / 文档B（处理节点）：表示生成或处理文档B。
multiple documents / 多文档（处理节点）：堆叠波形矩形，表示多份文档输出。
manual input / 手工输入（处理节点）：梯形节点，表示人工输入数据。
alternate process / 可选处理（处理节点）：圆角矩形，表示替代处理步骤。
delay / 延迟（处理节点）：半圆矩形，表示流程中的延迟等待。

三、流程说明
本流程图为流程图符号标准示例，用于展示常见流程图图形元素及其含义。流程从“开始/结束”节点出发，经判断节点后分为三条典型分支：左侧为“处理→文档→多文档”并循环回起点；中间为“预定义子程序→可选处理→延迟”；右侧为“数据输入→手工输入→可选处理”。整体结构呈现决策后的多路径并行演示，不对应具体业务逻辑。
