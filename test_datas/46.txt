扫地机器人工作路径流程文字文档
一、流程概述
开始 → 开机 → 扫描环境 → 生成地图与定位 → 规划路径 → 路径数据 → 启动吸尘 → 沿路径行进 → 是否完成路径？ → 关闭吸尘 / 电量低？ → 关闭吸尘 / 尘盒已满？ → 关闭吸尘 / 沿路径行进（循环） → 返回充电座 → 关机 → 完成

二、详细步骤说明
开始（起止节点）：扫地机器人工作流程启动
Power On（处理节点）：机器人开机
Scan Environment（处理节点）：扫描周围环境
Generate Map and Location（处理节点）：生成地图并确定自身位置
Plan route（处理节点）：规划清扫路径
Route（处理节点）：路径数据存储/输出
Vacuum On（处理节点）：启动吸尘功能
Follow route（处理节点）：沿规划路径行进
Finished Route?（判断节点）：判断路径是否已完成；若是，进入结束流程；若否，继续检查电量
Battery Low?（判断节点）：判断电量是否过低；若是，进入结束流程；若否，继续检查尘盒
Vacuum full?（判断节点）：判断尘盒是否已满；若是，停止并报警；若否，返回继续沿路径行进
Vacuum Off（处理节点）：关闭吸尘功能
Return power dock（处理节点）：返回充电座
Stop moving（处理节点）：停止移动
Error indicator On（处理节点）：开启错误指示灯
Power Off（处理节点）：关闭机器人电源
完成（起止节点）：流程结束

三、流程说明
本流程为带分支判断与循环回退的机器人控制流程。机器人开机并完成环境感知与路径规划后，沿路径循环清扫；期间实时检测路径完成状态、电量、尘盒容量三种情况，任意一种触发条件满足时即退出循环并执行相应的停机/回充/报警处理。
