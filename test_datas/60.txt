PID 数字控制算法流程文字文档
一、流程概述
开始 → 计算控制参数 P、I、D → 初始化历史误差 → 输入采样值 → 计算偏差 → 判断偏差绝对值是否小于等于阈值 → 计算控制增量 → 输出控制增量 → 更新历史误差 → 判断采样时刻是否到来 → 循环/结束

二、详细步骤说明
开始（起止节点）：流程启动，节点文字为“开始”
计算控制参数 P、I、D（处理节点）：节点文字为“计算控制参数P、I、D”，表示初始化 PID 控制器的比例、积分、微分参数
初始化历史误差（处理节点）：节点文字为“e(k-1)=e(k-2)=0”，将前两次误差初始化为 0
输入采样值（处理节点）：节点文字为“输入本次采样c(k)”，读取当前采样值 c(k)；外部反馈路径为 A/D → DC-DC 变换电路 → PWM → 输出 ΔP(k)
计算偏差（处理节点）：节点文字为“计算偏差 e(k)=r(k)-c(k)”，根据设定值 r(k) 与采样值 c(k) 计算当前误差
判断偏差绝对值是否小于等于阈值（判断节点）：节点文字为“|e(k)|≤ε”；若是，进入“ΔP(k)=0”；若否，进入“ΔP(k)=P×e(k)-I×e(k-1)+D×e(k-2)”
ΔP(k)=0（处理节点）：当误差在允许范围内时，控制增量为 0
计算 PID 控制增量（处理节点）：节点文字为“ΔP(k)=P×e(k)-I×e(k-1)+D×e(k-2)”，根据 PID 公式计算控制增量
输出控制增量（处理节点）：节点文字为“输出ΔP(k)”，将计算得到的控制增量输出到 PWM 模块
更新历史误差（处理节点）：节点文字为“e(k-1)→e(k-2), e(k)→e(k-1)”，将当前误差和前一次误差进行移位更新
采样时刻是否到来（判断节点）：节点文字为“采样时刻到来?”；若否，返回“输入本次采样c(k)”继续等待下一次采样；若是，返回“计算偏差”步骤进入下一个控制周期
完成（起止节点）：控制算法持续循环运行，流程在逻辑上结束

三、流程说明
本流程为带循环反馈的 PID 数字控制算法流程图。流程在每个采样周期内完成采样、偏差计算、PID 增量计算、输出和误差更新；通过“采样时刻是否到来”的判断实现周期性循环控制，同时右侧的 PWM→DC-DC→A/D 路径构成闭环反馈，体现了典型的数字 PID 闭环控制结构。
