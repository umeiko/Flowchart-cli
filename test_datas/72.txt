Find the sum of 529 and 256流程文字文档
一、流程概述
开始 → Read A → Read B → Calculate Sum as A + B → Print Sum → 结束

二、详细步骤说明
开始（起止节点）：流程启动，开始求两数之和
Read A（处理节点）：读取第一个数 A（示例中 A = 529）
Read B（处理节点）：读取第二个数 B（示例中 B = 256）
Calculate Sum as A + B（处理节点）：计算 A 与 B 的和（示例中 Sum = 529 + 256）
Print Sum（处理节点）：输出求和结果（示例中 Sum = 785）
结束（起止节点）：流程结束

三、流程说明
本流程为线性顺序流程，依次完成两个数的读取、相加与输出，无分支判断环节。示例右侧还展示了具体数值 529 与 256 的完整计算过程。
