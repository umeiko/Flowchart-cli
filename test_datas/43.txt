主序列执行与输入中断处理流程文字文档
一、流程概述
开始 → 200 启动主序列 → 210 执行主序列 → 220 输入手段是否被激活？ → 230 继续执行主序列 / 240 中断主序列并设置中断标志 → 250 识别激活的输入手段 → 260 获取并执行特定子序列 → 270 恢复主序列 → 280 执行周期是否结束？ → 完成

二、详细步骤说明
开始（起止节点）：流程启动
200 Initiate main sequence（处理节点）：初始化并启动主序列
210 Execute main sequence（处理节点）：执行主序列
220 Input means activated?（判断节点）：判断是否有输入手段被激活；若否，继续执行主序列；若是，进入中断处理分支
230 Continue execution of main sequence（处理节点）：无输入激活，继续执行主序列
240 Interrupt main sequence and set interrupt flag（处理节点）：有输入激活，中断主序列并设置中断标志
250 Identify activated input means（处理节点）：识别被激活的输入手段
260 Retrieve and execute specific sub sequence（处理节点）：获取并执行对应的特定子序列
270 Resume main sequence（处理节点）：子序列执行完毕后恢复主序列
280 Execution period ended?（判断节点）：判断执行周期是否结束；若否，返回重新执行主序列；若是，结束流程
完成（起止节点）：流程结束

三、流程说明
本流程为带分支判断与循环回退的主程序执行流程。主序列执行过程中会轮询检测输入手段是否被激活；若被激活则进入中断处理分支，执行相应子序列后恢复主序列，随后检查执行周期是否结束，未结束则循环继续执行。
