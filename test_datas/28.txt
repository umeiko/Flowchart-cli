BuildC 数组构建流程文字文档
一、流程概述
开始 → 声明整型索引 → 循环初始化 → 计算数组元素 → 循环递增 → 完成

二、详细步骤说明
开始（起止节点）：流程启动，函数/模块为 BuildC (Real Array C)
Integer Index（处理节点）：声明一个整型索引变量 Index
Index = 0 to Size(C) - 1（判断节点/循环条件）：判断索引是否从 0 遍历到数组 C 大小减 1；若是，执行元素计算；若否，流程结束
C[Index] = Index * 9 / 5 + 32（处理节点）：根据当前索引计算数组元素值，公式为摄氏度转华氏度的线性变换
完成（起止节点）：遍历结束，数组 C 构建完成

三、流程说明
本流程为典型的循环顺序流程。从索引 0 开始，依次遍历数组 C 的每个位置，使用公式 C[Index] = Index * 9 / 5 + 32 计算并赋值，直到索引超出范围后结束。
