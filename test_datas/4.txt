电路板波峰焊检测流程文字文档
一、流程概述
开始 → 装载板件 → 插入通孔元件 → 放入波峰焊看板 → 载入波峰焊机 → 取出并送入检验看板 → 修剪引脚并检查 → 是否有缺陷？ → [修复缺陷后重新检查 / 放入板级测试看板] → 结束

二、详细步骤说明
开始（起止节点）：波峰焊检测流程启动
Load board onto fixture / 装载板件到夹具（处理节点）：将电路板安装到固定夹具上
Stuff thru-hole components / 插入通孔元件（处理节点）：把通孔元件插装到电路板上
Put board in wavesolder kanban / 放入波峰焊看板（处理节点）：将板件放置到波峰焊看板区域
Load board into wavesolder / 载入波峰焊机（处理节点）：把板件送入波峰焊设备进行焊接
Pull from wave & put in inspection kanban / 从焊波取出并放入检验看板（处理节点）：焊接完成后取出板件并移至检验区
Trim leads and inspect / re-inspect / 修剪引脚并检查/复验（处理节点）：修剪多余引脚并进行外观及焊接质量检查
Has Defects? / 是否有缺陷？（判断节点）：判断板件是否存在焊接或元件缺陷
Repair defects / 修复缺陷（处理节点）：对发现的缺陷进行修复，修复后返回重新检查
Place in board-level test kanban / 放入板级测试看板（处理节点）：无缺陷的板件进入板级测试环节
结束（起止节点）：波峰焊检测流程结束

三、流程说明
本流程为带循环回退的线性顺序流程。流程前半段按装配、焊接顺序依次执行；在“修剪引脚并检查”后通过判断节点检验质量，若存在缺陷则进入“修复缺陷”并回退到检查节点重新检查，形成质量控制循环；只有确认无缺陷后才进入下一测试环节。整体体现了生产过程中的质量闭环管理。
