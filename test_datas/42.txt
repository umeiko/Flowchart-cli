星级评分输入校验流程文字文档
一、流程概述
开始 → 输入星级评分 → 星级评分是否越界 → 显示无效提示 → 重新输入星级评分 → 星级评分是否越界 → 显示感谢 → 完成

二、详细步骤说明
开始（起止节点）：星级评分输入流程启动
输入星级评分（处理节点）：提示用户输入 0 到 5 之间的星级评分（starRating = INPUT("Enter a star rating between 0 and 5?"））
星级评分是否越界（判断节点）：判断 starRating < 0 或 starRating > 5；若条件成立（越界），进入循环处理，否则直接输出感谢
显示无效提示（处理节点）：显示"Invalid Star Rating - Try Again!"，提示用户输入无效
重新输入星级评分（处理节点）：再次提示用户输入 0 到 5 之间的星级评分
显示感谢（处理节点）：星级评分合法，显示"Thank you!"
完成（起止节点）：流程结束

三、流程说明
本流程为带循环回退的输入校验流程。使用 WHILE 循环持续检查用户输入的星级评分是否处于 [0, 5] 范围内；若越界则显示无效提示并重新输入，直到输入合法后显示感谢信息并结束。
