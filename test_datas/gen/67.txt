充电安全定时器与看门狗流程文字文档
一、流程概述
开始 → 启动安全定时器 → 安全定时器是否超时？ → 充电是否完成？ → I²C是否执行读写？ → 启动看门狗定时器 → 充电是否完成？ → 安全定时器是否超时？ → 看门狗定时器是否超时？ → 是否收到软件看门狗复位？ → 重置I²C默认值并重启安全定时器 → 返回启动安全定时器

二、详细步骤说明
Start Safety Timer / 启动安全定时器（处理节点）：流程启动，开始安全定时计时。
Safety timer expired? / 安全定时器是否超时？（判断节点）：判断安全定时器是否超时；若“是”，触发安全定时器故障。
Safety timer fault / 安全定时器故障（起止节点）：安全定时器超时后的故障状态。
Charging suspended. Enter suspended mode. Fault indicated in STAT registers. / 充电挂起，进入挂起模式并在STAT寄存器中标记故障（处理节点）：故障发生后的处理动作。
Charge Done? I_CHG < I_TERM / 充电是否完成？（判断节点）：判断充电电流是否小于终止电流，即充电是否完成；若“是”，更新STAT状态位。
STAT = Hi, Update STAT bits / STAT置高并更新STAT位（处理节点）：标记充电完成状态。
I²C Read/Write performed? / 是否执行I²C读写？（判断节点）：判断是否有I²C读写操作；若“否”，返回启动安全定时器；若“是”，启动看门狗定时器。
Start watchdog timer / 启动看门狗定时器（处理节点）：启动看门狗定时器监控。
Charge Done? I_CHG < I_TERM / 充电是否完成？（判断节点）：再次判断充电是否完成；若“是”，更新STAT状态位。
Safety timer expired? / 安全定时器是否超时？（判断节点）：在看门狗监控阶段再次检查安全定时器；若“是”，触发故障处理。
WD timer expired? / 看门狗定时器是否超时？（判断节点）：判断看门狗定时器是否超时；若“是”，重置默认值并重启安全定时器。
Received software watchdog RESET? / 是否收到软件看门狗复位？（判断节点）：判断是否收到软件看门狗复位信号；若“是”，重置并重启；若“否”，复位看门狗定时器并继续监控。
Reset watchdog timer / 复位看门狗定时器（处理节点）：清除看门狗计数，继续监控。
Reset to default values in I²C register, Restart 40 min safety timer / 重置I²C寄存器默认值并重启40分钟安全定时器（处理节点）：系统复位并重新启动安全定时器。

三、流程说明
本流程为典型的嵌入式充电安全管理流程，包含多层判断与循环回退机制。安全定时器和看门狗定时器双重监控充电状态，任何超时或复位条件都会触发相应的故障处理或重启操作；I²C读写是看门狗监控的入口条件，未执行I²C读写时流程回到安全定时器起点继续轮询。
