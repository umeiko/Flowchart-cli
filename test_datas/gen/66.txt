研究生网上报名流程文字文档
一、流程概述
开始 → 登录中国研究生招生信息网 → 免费注册 → 进入研究生网上报名系统 → 是否报过名 → （未报过名）阅读公告和考试承诺书并点击认可 → 阅读网报公告并选择招生单位/考试方式/专项计划 → 填写个人信息（1） → 填写个人信息（2） → 选择报考专业、研究方向及考试科目 → 选择报考点并阅读网报公告 → 核对填报信息并输入校验码提交 → 生成并牢记报名号 → （北京等省市）网上支付/（其他省市）报名完毕 → 现场确认、照相并缴费 → 登录研招网下载准考证打印 → 考试 → 完成

二、详细步骤说明
登录中国研究生招生信息网（处理节点）：访问研招网 yz.chsi.com.cn 或 yz.chsi.cn。
免费注册（处理节点）：在研招网进行免费用户注册。
进入研究生网上报名系统（处理节点）：注册后进入网上报名系统。
是否报过名（判断节点）：判断考生此前是否已报名；若“已报过名”，跳转至“修改或查询报名信息”；若“未报过名”，继续新报名流程。
阅读公告和考试承诺书并点击认可（处理节点）：阅读相关公告及考试承诺书并确认同意。
仔细阅读各省以及招生单位网报公告并选择招生单位、考试方式及专项计划（处理节点）：阅读公告并选择报考单位、考试方式与专项计划。
填写个人信息（1）（处理节点）：填写第一部分个人信息。
填写个人信息（2）（处理节点）：填写第二部分个人信息。
选择报考专业、研究方向以及考试科目（处理节点）：选择报考专业、研究方向和考试科目。
选择报考点并阅读省、报名点网报公告（处理节点）：选择报考点并阅读相关公告。
核对填报信息并输入校验码提交（处理节点）：核对报名信息，输入校验码后提交。
生成并牢记报名号（处理节点）：系统生成报名号，考生需牢记。
网上支付（处理节点）：在北京、天津、河北、山东、河南、湖南、广西、四川报考点报名的考生需完成网上支付。
报名完毕（处理节点）：在其他省市报考点报名或完成网上支付后，报名结束。
现场确认，照相并缴费（处理节点）：按规定时间到报考点进行现场确认、拍照并缴费。
使用网报时注册的用户名密码登录研招网并下载准考证打印（处理节点）：登录系统下载并打印准考证。
考试（起止节点）：参加全国硕士研究生招生考试，流程结束。
修改或查询报名信息（处理节点）：已报名考生的信息修改或查询入口。
系统测试和预报名（处理节点）：2013年9月25日—28日进行系统测试和预报名，报名数据有效。
正式报名（处理节点）：2013年10月10日—31日正式报名。

三、流程说明
本流程为带分支判断的报名业务流程。在“是否报过名”处分为新报名和已报名两条路径；在“生成并牢记报名号”后按报考点所在地分为“网上支付”和“报名完毕”两个分支，最终汇合进行现场确认。右侧时间轴标注了各阶段的时间节点，体现了流程的时间约束。
