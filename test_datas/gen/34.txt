正数输入流程文字文档
一、流程概述
start → ask user for a positive number → n > 0? → print "positive" → end

二、详细步骤说明
start（起止节点）：流程启动
ask user for a positive number（处理节点）：提示用户输入一个正数
n > 0?（判断节点）：判断输入的数值 n 是否大于 0；若是则进入打印步骤，否则重新提示用户输入
print "positive"（处理节点）：输出字符串 "positive"，表示输入的是正数
end（起止节点）：流程结束

三、流程说明
本流程为带循环回退的判断流程。当用户输入的数值不满足大于 0 的条件时，流程会回退到输入提示节点，重新请求用户输入，直到输入正数后输出结果并结束。
