# 一体化存储系统（SAN + NAS）架构分层解析
架构逻辑总览


## 1. 数据访问协议层（接入层）
- **块存储协议（SAN）**：iSCSI / FC（光纤通道）/ NVMe-oF（原图简称 NOF）
- **文件存储协议（NAS）**：NFS / CIFS（SMB）

## 2. DataService 层，包含：

    ### 智能服务层（Smart 系列）
    - **SmartThin**：精简配置，按需分配容量
    - **SmartCache**：智能缓存，使用 SSD 加速热数据
    - **SmartPartition**：智能分区，保障关键业务 QoS
    - **SmartTier**：智能数据分层，自动在 SSD 与 HDD 间迁移数据

    ### 高级数据服务层（Hyper 系列 / 全局特性）
    - **空间效率优化**：全局重删（Global Deduplication）、数据压缩（Data Compression）
    - **数据保护与容灾**：全局快照（Global Snapshot）
    - **缓存与分流**：全局缓存（Global Cache）+ 冷热数据分流（自动分层）
    - **运维与均衡**：全局再平衡（Global Rebalance）、后台数据迁移
    - **写优化机制**：NVMe ROW 与满分条写策略，降低写放大，发挥闪存性能

## 4. 核心数据逻辑层
- **左侧 —— NAS 文件系统**：管理文件目录、元数据，对应 NFS/CIFS
- **右侧 —— SAN 空间**：管理 LUN 和块映射，对应 iSCSI/FC/NVMe

## 5. **存储池（Storage Pool）**：一系列存储基础特性
- 冷热数据分流
- 全局磨损均衡
- ROW满分条写
- 全局重删
- 后台相似缩减
- 全局垃圾回收

- SCM
- NVME
